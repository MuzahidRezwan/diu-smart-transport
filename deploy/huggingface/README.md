# DIU Smart Transport: live demo

Transport office dashboard, student/faculty app and the ridership model of
[DIU Smart Transport](https://github.com/MuzahidRezwan/diu-smart-transport), running with sample data.

- **Transport office:** choose *Transport office*, press *Fill in* (ID `710215`). No 2FA in the demo.
- **Student / faculty:** *Sign in with DIU account*, then type `232-35-797` (student) or `710410` (faculty) on the stand-in university page.

Open the app on its own address (the `.hf.space` link) rather than inside this page, so sign-in survives a reload.
Everything is sample data: sign-in and payments are simulated, and the data resets whenever the Space restarts.

This file and the Space are generated by `.github/workflows/deploy-demo.yml`; edit them in the GitHub repository.
